### Qué hacemos

| | |
|---|---|
| **Kinesiología** | Objetivos centrados en las necesidades individuales de cada paciente. |
| **Fonoaudiología** | Abordaje especializado, integrado al plan interdisciplinario. |
| **Terapia Ocupacional** | Herramientas para recuperar autonomía en las tareas del día a día. |

### Cómo trabajamos

- **Rehabilitación post hospitalaria:** acompañamos el regreso al hogar, buscando un nuevo equilibrio entre el paciente y su entorno.
- **Rehabilitación en el domicilio:** planes de trabajo únicos y personalizados, a partir de una evaluación exhaustiva del caso.
- **Atención a pacientes particulares:** cuidados y terapias especializadas, en el hogar o en centros de rehabilitación.
- **Kida para empresas:** procesos y metodologías adaptados a la estructura de cada institución de salud.
